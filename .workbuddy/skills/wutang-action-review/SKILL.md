# Skill: wutang-action-review

## 用途与职责
1. 记录当事人对「行动牌」或自定义微行动的反馈（做到了、做了一部分、还没开始、这个方法不适合我）。
2. 提供温暖、接纳式的反馈反馈语：
   - 若反馈「还没开始」或「做了一部分」：提醒「能觉察并诚实记录，本身就是一种前进，不必苛责自己」。
   - 若反馈「这个方法不适合我」：提醒「每个人节奏不同，随时可以换一个更自在的微动作」。
3. 根据一段时期的真实签到与行动数据，生成心境日历与每周回顾摘要。
4. 真实性铁律：记录不足时直接说明「样本较少，暂不总结规律」，严禁模型凭空编造情绪周期或患病趋势。

## 输入格式
```json
{
  "action_id": "A-002",
  "action_title": "先给自己一点时间",
  "feedback_status": "partially_completed",
  "user_note": "跟同事说了容我想想，但心里还是有点内疚"
}
```

## 输出格式
```json
{
  "review_id": "AR-20261019-9f1a",
  "status": "recorded",
  "encouragement": "你已经迈出了暂停回应的宝贵第一步！心里的内疚是多年讨好习惯的惯性回声，给它一点时间慢慢消散就好。",
  "adjustment_suggestion": "明天试试在心里对自己默念一遍『我的时间也是时间』，继续保持这微小的边界。"
}
```
