# Skill 5 · 东方解忧笺渲染（oriental-relief-card-render）

> 悟堂·东方解忧处的核心视觉卡片资产生成技能。将一次反思转化为用户可带走、可保存、可分享的典雅信笺载体。

## 一、触发条件

会话完成三张解忧牌与四步回应的组织后，用户点击「生成东方解忧笺」或系统生成卡片交付资产时调用。

## 二、输入参数

| 字段 | 来源 | 必填 | 说明 |
|---|---|---|---|
| `theme_tag` | `wutang-card-session` | ✅ | 场景主题（去班味 / 松绑 / 安住 / 破局） |
| `mindset_card` | `wutang-card-session` | ✅ | 包含心境提示核心提问 |
| `wisdom_card` | `wutang-card-session` | ✅ | 包含已核验经典原文、出处与现代转释 |
| `action_card` | `wutang-card-session` | ✅ | 包含微行动名称与步骤 |
| `is_public_share` | 前端用户切换 | 否 | 是否为「公开分享版」（默认 `false`） |
| `sage_info` | 先贤印章资料 | 否 | 先贤头像、称号与朝代印章信息 |

## 三、排版与内容规范（PRD 2.0 §6.6 / §9.1）

1. **视觉规范**：
   - 4:5 典雅信笺比例（Retina 2x 高清：1520 × 2080px 或移动端自适应矢量）。
   - 配色：暖白宣纸底色 `#FCF9F2`、深墨文字 `#262421`、朱红方印 `#8F2928`、雅金徽章 `#A67C38`、淡雅细边框 `#D6CAB8`。
   - 避免使用任何占卜符号、塔罗牌阵、星盘或迷信元素。

2. **卡面内容四要素**：
   - **顶部印信**：悟堂朱红方印「悟」+「悟 堂 · 东 方 解 忧 处」品牌标识。
   - **核心经典**：宋体呈现已核验古籍金句（如「君子求诸己，小人求诸人」）+ 可追溯出处（《论语·卫灵公》）。
   - **现代解读**：一两句温和白话启发，与原文在排版上独立。
   - **微行动信盒**：1–5 分钟可执行的小动作。
   - **底部箴言**：「让古老智慧，用今天的人听得懂的方式活着」。

3. **双版本安全隔离**：
   - **个人保存版**：包含心境启迪与微行动，**严禁**包含原始倾诉、姓名、单位、城市或具体事件。
   - **公开分享版**：进一步剥离特定情境叙述，只保留普适经典哲学与微行动，适合转发朋友圈或社交平台。
   - 明确附注：个人卡片分享与公开案例授权互不干涉。
