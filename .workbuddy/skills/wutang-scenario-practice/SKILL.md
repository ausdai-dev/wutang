# Skill: wutang-scenario-practice

## 用途与职责
1. 支持 5 个经典沟通场景（拒绝不合理请求、表达真实需要、面对工作批评、提出不同意见、重要谈话演练）。
2. 由 AI 扮演对话对手，根据当事人的练习发言做出贴近真实的应答。
3. 提供 4 维非评判沟通反馈：
   - 表达是否清晰
   - 内容是否具体
   - 是否稳固保留了自身边界
   - 是否照顾到沟通双方的体面与尊重
4. 输出 1~2 组高情商东方智慧替代表达范式，供当事人参考借鉴。
5. 安全边界：若在角色扮演中发现家暴、严重威胁、虐待或极端自伤风险，立即终止演练并跳转安全支持。

## 输入格式
```json
{
  "scenario_id": "sc-refuse-request",
  "user_draft": "我今晚也挺忙的，你找别人去吧，别老推给我。",
  "conversation_history": []
}
```
