# Skill: wutang-journal-organizer

## 用途与职责
1. 接收用户书写或粘贴的日常倾诉文本。
2. 结构化提炼 5 个维度：
   - 今天发生的事（事件客观事实）
   - 当时的想法（用户自述的脑海念头）
   - 感受到的情绪（精准复述或提炼的情绪词）
   - 可能在意的需要（AI 提示，必须标明「待当事人确认」）
   - 愿意尝试的下一步（低阻力微动作选项）
3. 绝不强加判断或指责，尊重用户对每一项提炼内容的自由编辑与删除权利。
4. 默认不上传或长久存储，只有用户主动点击保存后才写入本地日记账。

## 输入格式
```json
{
  "raw_text": "今天和主管对方案，他又打断我好几次，我当时很懵，后来觉得特别憋屈，开始怀疑自己是不是不适合这份工作。",
  "consent_to_save": false
}
```

## 输出格式
```json
{
  "journal_id": "J-20261019-33c4",
  "event_summary": "在今天的方案讨论会上被主管多次打断讲话。",
  "thoughts": "感觉自己没有被尊重，随后陷入了对职业适合度的自我怀疑与否定。",
  "feelings": ["憋屈", "发懵", "失落", "焦虑"],
  "possible_needs": "【待你确认】希望沟通能获得起码的倾听与表达空间，专业价值得到客观认可。",
  "next_step": "今晚先把情绪和事实分开写，明天在微信里简短文字确认主管对方案的实质修改意见。",
  "ai_inference_status": "requires_user_confirmation"
}
```
