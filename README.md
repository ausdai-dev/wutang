# 悟堂·东方解忧处

> 面向成年人的日常情绪整理工具 + 面向公益内容主理人的 WorkBuddy 内容工作流引擎
>
> **核心主张**：不说教，先接住；借古人的智慧，走好眼前一步。

---

## 这是什么

一条日常困扰进来，经过四个阶段出去：

```
用户输入  →  风险分流  →  四步解忧方  →  东方解忧笺
                              │
                              └─ 若另有授权 → 脱敏 → 公众号文章草稿（待主理人审核）
```

**核心差异化不是「AI 会引用国学」，而是「从一次输入，到一次有边界的回应，再到经授权的内容资产沉淀」，全流程可检查、可复用、可验证。**

## 快速开始

```bash
# 1. 构建知识库与前端（数据 → classics.csv / classics.json / index.html）
python scripts/build_knowledge.py
python scripts/build_frontend.py

# 2. 跑端到端工作流（风险分流 + 引用核验 + 11 条案例 → 全部产物）
python scripts/wutang_pipeline.py
```

打开 `frontend/index.html` 即可试用用户端（单文件、可离线、无需后端）。

### 本轮实际修掉的问题（如实记录）

1. **隐晦危机表达漏判 2 处**（SAFE-01 / SAFE-05）。根因是纯子串匹配：
   词表写「活着没意思」而实际是「活着**没什么**意思」；正则写「不再」而实际是「不**要**再醒来」。
   → 升级为句式匹配，复跑 14/14。**纯关键词表无法覆盖隐晦表达。**
2. **引用出处粒度不一致**（词牌/篇名混写在 `book` 字段）。→ 拆分为 `book` + `chapter`。
3. **脱敏 3 处缺陷**：「××广告公司」替换后残留「公司」；「张伟」未识别（吞掉了「一」）；
   日期替换读起来别扭。→ 引入百家姓表 + 后缀整体匹配，输出变干净。
4. **边界案例（`review`）未拦截公开内容生成**。`privacy_review()` 当时只拦 `high_risk`，
   导致「涉未成年人」等边界案例在已授权时仍被判为可生成草稿——**与 `safety_rules.md` §1
   分流表「`review` 不出具普通四步回应」直接冲突**。→ 补 `review` 分支，授权不改变结论。
   这是**代码漏了规则**，不是规则本身有问题；已同步回 4 处 Skill / Agent 表述。
5. **周报变相泄露样本构成**。F-08 周报在样本低于披露阈值时，第四节仍逐条标注
   「出现于 1 条授权案例」——样本只有 3 条时，这等于把每条都点出来了。
   → 低于阈值时不展示频次、按字母序列出标签；「主题印象」段也改为**从数据推导**，
   不再硬编码一段与数据无关的描述。

## 数据纪律

- **不编造**。检索不到就写「未找到可信出处」，不补造书名篇章。
- **可溯源**。每条引用携带 `source_id`，可在 `knowledge/source_index.md` 查到核验台账。
- **三级核验状态**：`verified`（可作直接引语）/ `needs_review`（须标「辑录·待复核」）/ `not_found`（禁止引用）。
- **主动订正**。本轮订正了 5 处出处标注，其中最典型的是：
  「物忌全胜，事忌全美，人忌全盛」原素材标为弘一法师《格言别录》原创，
  **实出清·金缨《格言联璧·持躬类》**，弘一法师是辑录引用者。
- **区分「事实 / 推断 / 建议」**，不混着写。

## 安全边界（不因任何理由妥协）

- 不提供医学诊断、心理治疗、危机干预或疗效承诺。
- 不宣称「100% 识别危机」「100% 引文准确」。
- 未授权不进入公开内容流程；**同意分享卡片 ≠ 同意公开原始问题**。
- 公开内容一律「待主理人审核」，**不自动发布**。
- 高风险案例**永不**进入公开内容生成。
- **边界案例（涉未成年人 / 医疗用药 / 精神科 / 玄学诉求）同样不进入公开内容生成，授权不改变结论。**
- 演示结束后清理 `inbox/` 与 `output/` 中的临时文件。

## 已知技术限制

- 前端与流水线引擎是**确定性规则引擎**，不调用大模型。四步回应中的共情段由模板 + 用户原话
  片段生成，属于**离线降级版**；完整版由 WorkBuddy 专家团生成。
- **文章草稿同样是模板骨架**：正文按「职场 / 关系 / 深夜 / 成长」四类场景各写一段通用文案
  （本轮已按场景拆分，修复了此前所有草稿都用职场口吻的错配问题），经典引用与微行动是动态的，
  但**第一节的「案例梗概」为占位符，不自动生成**。这不等于 F-07 要求的「将个案改写为面向公众的
  主题文章」——该步必须由主理人或专家团据去标识化梗概完成。
- 风险分流为**关键词 + 正则双轨兜底**，不是语义理解，更不是临床判断工具。
  正式部署必须叠加模型语义判断并人工复核测试集。
- 经典语料 41 条为**小而精的人工核验样本**，覆盖面有限；未命中时会明确说明，不会编造。
