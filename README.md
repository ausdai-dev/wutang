## 二、快速开始

### 1. 环境准备与依赖安装

系统基于 Python 3.9+ 与 FastAPI，环境配置位于 `backend/.env`：

```bash
# 安装 Python 后台依赖
pip install -r backend/requirements.txt
```

### 2. 配置官方 DeepSeek API

在 `backend/.env`（或项目根目录 `.env`）中配置官方 DeepSeek 接口凭证：

```ini
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-v4-flash
LLM_API_KEY=sk-your-deepseek-api-key
LLM_TIMEOUT=30.0
ENABLE_FALLBACK_STREAM=true
```

### 3. 一键启动后台服务

```bash
python -m backend.app
# 或运行批处理脚本:
run_backend.bat
```

- 后台地址：`http://localhost:8000`
- 交互界面：`http://localhost:8000/`
- API 文档：`http://localhost:8000/docs`
- 服务状态大屏：`http://localhost:8000/status`

### 4. 前端离线构建与全量自动化验收

悟堂支持**双模运行**：连接后台时由真实 DeepSeek 模型实时推理；若完全离线，通过内联静态引擎亦能 100% 完整运行：

```bash
# 重新编译内联单文件前端 (包含 108 卡牌图鉴、514 典籍与四大宗师立绘)
python scripts/build_frontend.py

# 运行前端 19 项 DOM 回归测试 (jsdom)
node scripts/verify_frontend.js

# 运行 PRD 3.0 综合全量验收套件 (38/38 全项通过)
python scripts/verify_prd3_all.py

# 运行 PRD 4.0 儒释道三学解惑与卡牌人生全量验收套件 (45/45 全项通过)
python scripts/verify_prd4_all.py
```

## 三、PRD 4.0 核心国学与卡牌人生架构

### 1. 儒释道三家专家团 (The Three Sages)
- **孔子（儒家·先师）**：代表「修己安人，知行合一」，引证《论语》《孟子》《大学》《中庸》《荀子》等。主色调东方朱砂红。
- **老子（道家·宗师）**：代表「道法自然，虚静逍遥」，引证《道德经》《庄子》《列子》《文子》等。主色调玄青墨色。
- **释迦牟尼（释家·觉者）**：代表「觉照破执，明心见性」，引证《金刚经》《心经》《六祖坛经》《法句经》《华严经》等。主色调佛陀金黄。
- **三圣圆桌（三教会通）**：三圣同台，各出法门，融汇贯通。主色调紫宸华彩。

### 2. 专属解脱之道卡牌与实体工业级 300 DPI 规范
- **正面布局**：宗师尊号、赛道篆印、核心解脱常道词、主理人昵称专属编号、二十四节气与农历干支、核心定心箴言、英文 Mantra。
- **背面布局**：所提困惑回响、宗师原典真诠印证、5分钟微习惯当下功课、悟堂官方防伪二维码。
- **印刷工业标准**：标准 TCG $63\text{mm} \times 88\text{mm}$ + $2\text{mm}$ 四边出血（实际尺寸 $67\text{mm} \times 92\text{mm}$，300 DPI 像素分辨率 $791 \times 1087\text{ px}$）。
- **一键 ZIP 打印包**：内置正面 CMYK/RGB 高清图、背面高清图、专色烫哑金遮罩图（FoilMask，黑色 100% K 专色版），以及给印务制作人员的《印务下单指南_README.txt》。
- **A4 9 宫格即时拼版**：前端内置 A4 纸张 9 宫格网格排版，用户在家通过普通喷墨/激光打印机即可一键打印裁切。

### 3. 儒释道卡牌人生 · 108 百八常道图鉴
- 共收录 108 张经典人生常道卡牌：
  - **儒家 36 张（修己安人）**：温润如玉、修己以敬、过则勿惮改、见贤思齐、慎独致远、反求诸己、和而不同、居敬穷理等。
  - **道家 36 张（虚静逍遥）**：上善若水、抱朴守拙、道法自然、为无为、致虚极、乘物游心、万物齐一、大巧若拙等。
  - **释家 36 张（明心觉照）**：明心见性、应无所住、如露如电、万法唯心、当下一念、不生不灭、烦恼即菩提、本来无一物等。
