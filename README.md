# 悟堂·东方解忧处（卡牌融合版 · PRD 2.0）

> 面向年轻职场与生活人群的日常情绪整理与东方智慧启发工具 + 面向内容主理人的 WorkBuddy 工业化内容工作流引擎
>
> **核心主张**：不说教，先接住；借古人的智慧，走好眼前一步。

---

## 一、这是什么

许多成年人的内耗，往往卡在「千头万绪不知从何说起」；而传统国学文化传播容易陷入「高高在上讲大道理」的窠臼。
**悟堂 PRD 2.0** 将「卡牌互动」与「结构化解忧」深度融合，提供从轻量觉察到行动落地的温和旅程：

```
                ┌── 入口 A：我有件心事（直接倾诉文本输入） ──┐
                │                                          │
用户进入 ───────┤                                          ├─→ 风险分流评估
                │                                          │    (high_risk / review / normal)
                └── 入口 B：抽一张今日觉察牌（3D翻转互动） ─┘                │
                                                                       ↓
┌─────────────────────────────────────────────────────────────────────────────────┐
│ 核心交付：三张解忧牌 (Three Relief Cards)                                         │
│ 01 心境牌（看见自己） → 02 东方智慧牌（换个视角 · 严谨核验） → 03 行动牌（走出一步）│
│ (单牌支持原地更换 / 行动支持自主选择：我愿意试一试 / 换个行动 / 今晚先不做)       │
└──────────────────────────────────────┬──────────────────────────────────────────┘
                                       │
                      ┌────────────────┴────────────────┐
                      ↓                                 ↓
       四步解忧方（完整文字详述）              东方解忧笺（4:5 国风信笺）
       01 听见了                              ├─ 个人自存版 📜（含微行动，去标识）
       02 古人有云（先贤印章+核验出处）       └─ 公开分享版 🌿（共读精选金句）
       03 试试这一招（5分钟低阻力微行动）         (绝不泄露用户原始私人心事)
       04 读这一段（经部典籍导读）
                      │
                      └─ 若另有用户明确授权 (L3) ──→ 匿名脱敏 ──→ 公众号文章草稿（待主理人审核）
```

**核心差异化**：
1. **不说教，先接住**：先用心境牌和共情接纳当下，再以古人智慧换个角度看，最后给出一个 5 分钟就能动手的小微步。
2. **出处绝对严谨**：500 条权威版本传世典籍考据（《论语》《道德经》《大学》等），每一条标明朝代作者、通行版本与唯一编号，绝不胡编伪名言。
3. **三级授权隔离**：个人使用与自存（L1）、公开分享卡片（L2）、案例编入公众号文章（L3）严格物理隔离，卡片绝不带入用户原始心事文本。

## 二、快速开始

### 1. 本地一键构建与启动

本项目为**纯本地、离线韧性架构**，无需配置数据库或外部复杂服务：

```bash
# 1. 构建资料库与单文件前端（数据打包内联到 frontend/index.html）
python scripts/build_knowledge.py
python scripts/build_frontend.py

# 2. 运行全套端到端质量测试（5 大测试套件，100% 自动化验证）
python scripts/wutang_pipeline.py
```

直接在浏览器中打开 `frontend/index.html`，即可体验完整的**用户端双入口**与**主理人工作台**。

## 六、安全红线与合规承诺

1. **非临床与非算命声明**：本产品为日常情绪疏解与东方经典文化启发工具，不提供心理疾病诊断、精神科处方、心理治疗，亦不提供任何形式的周易算命或前程预测。
2. **隐私保护三态隔离**：
   - **L1 个人回应**：用即走，不沉淀任何可关联身份的持久化档案。
   - **L2 卡片分享**：解忧笺仅提炼共性金句与行动建议，不含用户真实输入。
   - **L3 公共文章**：仅在用户显式打勾并记录时间戳的情况下进入去标识化处理流水线，且**必须由主理人人工复核后才可进入草稿准备，绝不自动发布**。
3. **出处考据诚信**：检索不到确切出处时坦诚标明「未找到可靠出处」，宁缺毋滥，永不生成杜撰伪名言。
