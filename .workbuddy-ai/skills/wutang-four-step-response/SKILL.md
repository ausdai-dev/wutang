# Skill 2 · 四步解忧方生成（wutang-four-step-response）

> 悟堂·东方解忧处核心回应生成技能。四步解忧方与三张解忧牌相辅相成：卡牌提供直观交互载体，四步方组织深层文化反思与落地路径。

## 一、触发条件

会话风险评估为 `normal`，且已通过 `wutang-card-session` 匹配或确定卡牌基础内容。

## 二、输入参数

| 字段 | 来源 | 必填 | 说明 |
|---|---|---|---|
| `session_id` | `wutang-card-session` | ✅ | 当前会话 ID |
| `user_text` | 用户输入 | 否 | 用户补充或直接输入的困扰文本 |
| `selected_theme` | 场景标签 | ✅ | `work` / `relation` / `night` / `growth` |
| `cards_data` | `wutang-card-session` | ✅ | 包含已匹配的心境牌、智慧牌、行动牌 |
| `risk_status` | 风险分流结果 | ✅ | 必须为 `normal` |

## 三、四步回应组织规则

### 1. 听见了（看见与共情）
- 用 2–3 句话接住用户明确表达的情绪，不使用心理学诊断术语，不作主观评判。
- 与心境牌主题相呼应，点明「这种纠结是许多人共同面对的人之常情」。
- 长度：40–90 字。

### 2. 古人有云（经典出处与现代视角）
- 原文、出处、白话解释、与当下的可能关联四要素分明呈现。
- 必须基于 `cards_data.wisdom` 中的已核验内容。
- **原文与现代解释在视觉与语义上必须严格分开**。
- 若资料库未命中可信条目，直陈「暂时未找到贴合且可信的原文」，不以伪造名言搪塞。

### 3. 试试这一招（可选择的微行动）
- 呈现 `cards_data.action` 中的具体低门槛行动（耗时 1–5 分钟）。
- 行动必须是可操作、可拒绝、可替换的。
- 明确提供「我愿意试试」「换个行动」「今天先不做」的自主空间。
- 不使用命令口吻，不将未执行行动定义为意志力薄弱或失败。

### 4. 读这一段（延伸考据与阅读）
- 指向已核验典籍的具体书名与篇章。
- 提供一句平静、克制的阅读心境提示（如：睡前翻一页即可，不求通读全篇）。
- 附带温和安全边界提醒。
