### 关键发现与修复（重要，后续别踩）

1. **DOC 下的 `.md` / `.mhtml` 其实是 MHTML 快照**，正文被 quoted-printable 编码包在 HTML 里。
   用 `email.message_from_binary_file` + `get_payload(decode=True)` 才能取出，直接读会全是乱码。
2. **隐晦危机表达漏判**（本轮最实质的 bug）：纯子串匹配覆盖不了
   「活着**没什么**意思」「不**要**再醒来」。→ 必须叠加**句式（正则）层**。已记入 safety_report R-002。
3. **前端 `#cardView{display:none}` 是 ID 选择器**，优先级压过 show() 用的 class → 卡片永远显示不出来。
   改用初始 `class="hidden"`。**这类 bug 只有真跑浏览器才发现**。
4. **古籍出处订正**：原素材把「物忌全胜，事忌全美，人忌全盛」等 7 条标为弘一法师《格言别录》，
   实出清·金缨《格言联璧》（弘一法师是辑录者）。已在 source_index.md 立订正台账。

### 环境经验

- 浏览器验证用 `agent-browser`（`npm i -g agent-browser` + `agent-browser install`，约 200MB）。
  截图参数是 `--full`，**不是** `--full-page`。
- `agent-browser click <sel>` 是真实鼠标点击，**元素在视口外会点空**。
  可靠做法：`agent-browser eval "document.getElementById('x').click()"`。
- 托管 venv 无 Pillow，需用 `binaries/python/envs/default/Scripts/python.exe`（含 Pillow）。

### 经验

- **「写了代码」≠「实现了规则」**：privacy_review 漏 review 分支，靠构造状态组合的测试才暴露。
  凡规则文件里写了的分支，都要有对应的测试用例去证明它真的生效。
- **模板化内容要防场景错配**：一份通用文案套所有场景，会在非目标场景读出违和感。
- **低于披露阈值时，任何计数都是泄露**：连「出现于 1 条」都不行。
