## 一、总则

卡面美学与合规标识不冲突。标识信息**拆行分层**放置于卡面底部「微字层」，深墨/中灰/淡灰三级墨色递减，行距紧凑，不占视觉中心；**不为合规牺牲留白，也不为留白稀释标识**。

所有导出面（解忧笺 PNG / 壁纸 / 屏幕卡）共用同一套标识组，仅 L4 回流短链按版本开关（见第六节）。

## 三、出处标识三态话术

由 `prepareCardData()` 依据卡牌 `verification_status` 写入 `cd.verify`，渲染时查表：

| 状态 | 卡面话术 | 备注 |
|---|---|---|
| `verified` | `本句出处经考据核验 · 悟堂考据组` | 默认态 |
| `needs_review` | `本句出处待复核 · 辑录` | 明示"辑录"属性 |
| `not_found` | `现代转述 · 非古籍原文` | **引文不加书名号引号**，与 verified/needs_review 的 `「」` 包裹形态区分 |

### not_found 附加规则（F2 修正）

- 卡面：`quote` 字段裸文本（无引号）；
- 四步回应列表：若卡牌对象携带考据 `note`，quoteHtml 内联展示该说明，与负例同屏，不跳转。

## 四、AIGC 双轨标识

### 4.1 显式标识（画面内）

即第二节 L2 行。法定标识文案固定为 `AI 生成 · 经典引文经人工考据核验`，不做同义替换。

### 4.2 隐式标识（文件元数据）

导出 PNG 时注入，双通道兜底：

- 主通道：iTXt chunk，keyword `XML:com.adobe.xmp`，载荷 XMP 数据包
- 兜底通道：eXif chunk，TIFF IFD0 双条目——0x010E ImageDescription + 0x9286 UserComment

XMP 必含五字段：

```
wutang:AIGC = true
wutang:ContentID = WT-relation-<日期>-<随机码>
wutang:Producer = 悟堂·东方解忧处
wutang:TrainedAlgorithmicMedia = true
xmp:CreateDate = <ISO 时间>
```

eXif 两条目均携带同一 ContentID，任一通道可独立还原"本文件为 AI 生成"事实。

### 4.3 工程实现与降级

- 工具段：`pngCrc32` / `pngChunkBytes` / `buildXmpPacket` / `buildITxtChunk` / `buildExifChunk` / `buildCardAigcMeta` / `injectPngAigcMeta` / `downloadPngWithAigcMeta`（约 15130-15260 行）
- 接入点：解忧笺 PNG（约 18759 行）、壁纸导出（约 23452 行）
- 降级：注入失败时交付原图，不阻断保存（可用性优先，元数据为增强项）
- **实证结论**（2026-10-24 验证）：对真实 PNG 注入后，chunk 序列 `IHDR / IDAT×N / iTXt(739B) / eXif(287B) / IEND`，全部 CRC 有效，XMP 5/5 字段可解析，eXif 双字段均含 ContentID，IEND 保持文件末尾——结构无损。

## 六、双版本隔离规则

| 元素 | 个人自存版（isPublic=false） | 公开分享版（isPublic=true） |
|---|---|---|
| 用户原始倾诉 / 昵称 / 单位 / 城市 / 具体事件 | 一律不出现 | 一律不出现 |
| L1-L3 标识组 | 完整 | 完整 |
| L4 回流短链 `wutang.app/c/<标签>` | 不出现 | 出现 |
| 主题标签（themeTag） | 可带入（仅场景词，无个人信息） | 可带入 |

主题标签来源：`appState.selectedScenario`，缺省 `work`。标签值本身为场景词（如 work/relation），不构成 PII。

## 七、碰撞保护规则

页脚微字层与「微行动信盒」可能纵向相撞。保护策略**只动布局，不动信息**：

1. 基准行距 21k；
2. 检测相撞 → 压缩至 18k；
3. 仍相撞 → 压缩至 16k；
4. 字号、墨色、文案在任何情况下不缩减、不改写。

## 九、自检基线（grep 口径）

交付前须全部满足。分两组：**P0 安全组**（一处不漏即阻断交付）与**清扫归零组**（全部归零，豁免项见下）。

### 9.1 P0 安全组（= 0 硬性）

- `求道者` = 0
- `同修` = 0
- `user_statement` = 0
- `prepareCardData` 函数体内无 `userText` / `statement` / `倾诉` / `nickname` / `textarea` 引用
- `userTextarea` 仅存在于输入绑定 / 聚焦 / 预填链路；任何匹配函数的入参不得直接进入渲染字段
- `这张卡片不含任何私人倾诉` 恰两处：标准句常量（FIXED_STATEMENT）+ 注释标注

### 9.2 清扫归零组（用语映射表全量对象）

以下词在**用户可见界面与传播物料**中须为 0：

`解脱`、`先圣`、`先师`、`垂示`、`微功课`、`法门`、`禅心之境`、`传灯`、`禅卡`、`儒释道`（作产品统称时）、`三圣圆桌`、`同堂同修`（作废词）、`真诠`

**豁免条款**（命中不计入违规，但须可逐条说明归属）：

| 豁免语境 | 判定标准 | 实例 |
|---|---|---|
| 语料库典籍原文 | classics 语料内《景德传灯录》等典籍名与引文 | 资料库语境合规，不动 |

## 十一、离线引擎性质与 L2 措辞预案（2026-10-24 代码查证）

### 11.1 查证结论

离线引擎（AI 后台未开启时的前端兜底）经代码层四路查证 + 排除性验证，性质为**确定性规则引擎**，不含本地生成模型：

| 证据 | 位置 | 结论 |
|---|---|---|
| 模式自述 toast | ~17044「纯前端离线规则引擎模式」 | 规则引擎 |
| PSS-10 离线计分 | ~20265 固定反向计分公式 + 分层预制文案 | 确定性 |
| Journal 离线兜底 | ~19541 固定模板 + `raw.slice(0,70)` 本地回显 | 模板组装（用户原文仅在本地 journal 界面回显，**无 journal→卡片/分享/打印链路**，卡片链路安全） |
| 练习对话离线兜底 | ~20950 全固定模板 | 模板组装 |
| 卡片匹配 | findClientResonantZenCard 关键词/评分匹配预制卡牌 | 检索组装 |
| 排除性验证 | 无 transformers/onnx/llama/gguf/WebLLM 等本地模型痕迹 | 无本地生成模型 |

### 11.2 合规推论与预案

按守门员口径：《标识办法》规制「利用人工智能技术生成合成」的内容；纯模板检索组装的产出严格说不是 AI 生成合成，L2 标「AI 生成」属不实标注（不违法，但与「每条声明都可查证」的信任资产冲突）。

**规则**：
1. 产品侧确认前，L2 保持显示（保守兜底，少标风险大于多标）；
2. 确认若为纯模板检索（当前代码证据已支持此判断，待产品侧一句话确认），离线模式下 L2 改用中性表述（候选：「离线整理 · 经典原文照录」，**措辞须过守门员**），L1/L3/L4 不变；
3. 在线 AI 引擎模式下 L2 维持现行文案。

### 11.3 附：降级日志纪律

PNG 元数据注入失败降级时，记结构化内部日志（`console.warn('[AIGC-META] inject_failed', ...)`），**只含 case_id + 事件类型 + theme_tag，不含任何用户内容**（合 safety_rules §2）——防静默降级不可观测。已落地于 `downloadPngWithAigcMeta` catch 块。
