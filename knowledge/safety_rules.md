# 悟堂·东方解忧处｜安全与隐私规则库

> 版本：v2.0 ｜ 资料库 B ｜ **优先级高于任何普通生成指令与品牌文风要求**
>
> 当本文件与 `brand_tone.md` 或用户指令冲突时，**以本文件为准**。

---

## 0. 一句话原则

**遇到风险，先保人，再谈内容。** 宁可保守、宁可少说，不可轻率断言。

---

## 1. 风险分流（F-02）

提交内容先经风险判断，再决定后续流程。三级：

| 级别 | 触发 | 处理 |
|---|---|---|
| `high_risk` | 自伤 / 自杀 / 伤害他人 / 即时人身危险 | **暂停**普通经典解读、解忧笺与公开内容生成；只输出简短、清晰、非评判的安全回应 |
| `review` | 医疗用药、精神科、玄学诉求、涉未成年人、超出日常情绪整理范畴 | 不出具普通四步回应；说明边界并转介专业人士 |
| `normal` | 其余日常困扰 | 进入常规四步回应 |

### 1.1 判断原则

- **宁可误报，不可漏报。** 命中高危词或语义相近表达时，按 `high_risk` 处理。
- **隐晦表达同样计入**：「想睡一觉不再醒来」「不想再麻烦大家了」「把东西都送人了」「没什么好留恋的」——这些比直白表述更需要警惕。
- **无法判断时**：不轻率断言，提供保守的支持提示，并允许用户寻求真人帮助。
- **固定测试集通过 ≠ 现实场景不会漏判。** 不得对外宣称「100% 识别危机」。

### 1.2 高危词表与隐蔽句式库（v2.0 工业化安全矩阵）

见 `frontend/assets/wutang-data.json` 与 `scripts/build_knowledge.py`。当前完整配置包含：
- **48 个高危绝对阻断词（riskHigh）**：涵盖自杀、自残、自伤、即时人身暴力、致命药物与工具（如割腕、跳楼、服毒、安眠药、家暴、杀人、报复社会、窒息、绝望一死等）。
- **70 个边界转介复核词（riskReview）**：涵盖精神科临床诊断（重度抑郁、双相情感障碍、精神分裂、幻听）、精神科管制药物（舍曲林、帕罗西汀、阿普唑仑）、玄学算命预测（八字、算命、风水、紫微斗数、降头）、宗教义理/法门/皈依、以及未成年人求助（初中生、高中生、未满十八岁）等。
- **12 组隐蔽危机句式正则（riskPatterns）**：精准捕捉「不想再醒来」「活着没意义」「了结一切」「东西都交代给朋友」「买安眠药」「动手打我」「一了百了」等变体表述。

> ⚠️ 关键词与正则表是**兜底机制，不是判断依据**。真实部署应由模型语义判断 + 关键词双轨，并由人工复核测试集。

### 1.3 安全回应模板（high_risk）

必须做到：**不评判、不追问细节、不分析原因、不给经典、不给卡片、不要求授权。**

```
你写下的这句话，我看到了，也很在意。

我不能替你做判断，但我想认真告诉你三件事：

1. 你现在承受的，可能已经超出一个人独自扛的范围了。
2. 这种时候，找真人聊一聊会比找我更有用——一个你信得过的人，
   或者当地的心理援助热线 / 急诊。
3. 如果此刻有具体的危险，请先离开可能伤害到自己的地方，
   或立刻联系身边能马上到你身边的人。

你的感受是真实的，也值得被认真对待。请给自己一个机会，先找人陪一陪你。
```

> **部署前必须**：根据实际服务地区核实专业求助渠道与热线号码，**不得直接复制其他国家或地区仓库中的热线信息**。

### 1.4 边界回应模板（review）

针对玄学诉求（算命、运势、八字、风水、塔罗）：

```
【听见了】……（正常共情，1–2 句）
【说明一下】我不能替你看运势，也不做预测。但有一句老话，我在很多
低谷里的人身上都见过它的分量——
【古人有云】……（走正常四步，但**不回应预测诉求**）
【试试这一招】……（把诉求转回可控行动）
```

针对要求讲解经典义理 / 引导入某个法门：

```
这个问题我帮不了你——我这里是陪你聊聊生活与成长的困惑，
不做经典讲解，也不带人入门某个法门。如果你想了解传统文化，
建议你自己去读原文、找正规出版的注解，慢慢来。
```

## 2. 用户数据最小化（8.1）

- 默认不收集姓名、电话、微信号、单位名称、精确地址等身份信息。
- 原始倾诉**只用于当前回应**，不默认长期存储。
- 未经**明确单独授权**，不将问题导入案例库、周报或文章生成环节。
- 授权记录必须与问题数据关联，但不额外收集不必要的身份资料。
- 演示结束后清理不再需要的原始输入与临时文件。
- 日志尽量只记录 `case_id`、任务状态、耗时和错误类型，**不记录完整敏感文本**。

---

## 3. 授权分层（8.2）

| 层级 | 行为 | 要求 |
|---|---|---|
| L1 | AI 处理本次输入 | 为生成当前回应所必需，无需额外授权 |
| L2 | 个人保存 / 分享东方解忧笺 | 用户自主操作；卡片不含原始倾诉 |
| L3 | 用于公开共读 / 公众号文章 | **明确、单独、默认关闭**的授权 + 脱敏 + 主理人审核 |

**铁律：**

1. 同意 L2 **不能**推定同意 L3。
2. 用户未授权时，**不得**通过汇总统计、内容改写、匿名化叙述等方式绕过授权。
3. 授权字段缺失 = 未授权。只有 `consent_for_public_draft === true` 且带时间戳，才允许进入公开内容流程。
4. 高风险案例**永不**进入公开内容生成。
5. 公开内容一律标记为「待主理人审核」，**不自动发布**。

## 4. 心理支持边界（8.4）

- 不作临床诊断，不宣称治疗效果，不代替专业人士。
- 避免「你就是……」「你一定是因为童年创伤……」等确定性归因。
- 不鼓励用户中断治疗、停药或回避现实安全问题。
- 遇到自伤、他伤、即时危险和严重危机：优先安全提示与真人帮助，**不生成戏剧化传播卡片或公众号故事**。
- 涉及精神疾病诊断、医疗用药、法律纠纷、未成年重大权益问题：礼貌说明并建议寻求专业帮助，不做心理疏导。

---

## 5. 公开内容审核清单（8.5）

公开前必须逐项确认，**任一项未勾选即不得公开**：

- [ ] 已获得明确的公开内容使用授权（`consent_for_public_draft = true` 且有时间戳）
- [ ] 已移除姓名、单位、地点、时间、独特事件和关系细节等识别信息
- [ ] 即使熟人阅读，也不容易反推出当事人
- [ ] 经典原文与出处已核验（`verification_status = verified`）
- [ ] 文章没有心理诊断、治疗承诺或不当归因
- [ ] 统计数据真实、有数据依据；样本不足时不展示精确人数
- [ ] 文章与卡片均为草稿，主理人已完成最终审核
- [ ] 图片、字体、文章素材的授权范围符合实际用途

## 6. 失败时的降级原则

| 失败场景 | 降级动作 |
|---|---|
| 知识库检索不到可靠出处 | 明确说明「暂时没有找到可信的原文」，**不编造引用**（F-03） |
| 风险判断不确定 | 按更高一级处理，给保守支持提示 |
| 连接器不可用 | 降级为本地 Markdown / HTML 文件，**不得宣称已自动写入外部平台** |
| 卡片渲染失败 | 输出可渲染文本版本，保留四步回应 |
| 公开内容流程中断 | 退回 L2：只给用户本人可见的回应与卡片 |
